인증 방식 안내

  • Bearer Token

    서비스 계정 토큰을 사용합니다. 클러스터 내부에서 실행 시 권장됩니다.

  • 클라이언트 인증서

    CA/클라이언트 인증서와 키를 사용합니다. 고가용성 환경에 적합합니다.

  • KubeConfig

    ~/.kube/config 파일을 그대로 붙여넣습니다. 가장 간편한 방법입니다.

토큰 생성 예시

관리자 권한의 서비스 계정 생성:

kubectl create sa ovworks-admin \
  -n kube-system

kubectl create clusterrolebinding \
  ovworks-admin \
  --clusterrole=cluster-admin \
  --serviceaccount=\
  kube-system:ovworks-admin

kubectl create token ovworks-admin \
  -n kube-system

운영 환경에서는 최소 권한 원칙을 적용하세요.
